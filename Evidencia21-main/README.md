Este proyecto permite verificar si una dirección de correo electrónico ha sido comprometida en alguna brecha de 
seguridad conocida, utilizando la API pública de *Have I Been Pwned (HIBP)*.

Estructura del proyecto:

	verificar_correo.py  #Script principal
 	registro.log  #Archivo de registro
	reporte.csv  #Reporte de resultados
	requirements.txt  #Dependencias del proyecto
 	README.md  #Documentación
